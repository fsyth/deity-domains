# Deity Domain Generator

A simple generator for creating gods with multiple domains for worldbuilding.

Click the button to generate a deity with a random combination of domains. Useful for quickly filling out a pantheon, inspiring new gods, or adding some strange divine flavour to a setting.

**[Try it here!](https://fsyth.github.io/deity-domains/)**

Some examples and the thought process behind this are [over on substack](https://turnbackcountry.substack.com/p/fantasy-writers-heres-a-tool-to-stop).
